# Website

Built with [Jekyll](https://jekyllrb.com/) and [al-folio](https://github.com/alshedivat/al-folio).

| To update     | Edit                       |
| ------------- | -------------------------- |
| Pages         | `_pages/`                  |
| Publications  | `_bibliography/papers.bib` |
| News          | `_news/`                   |
| Web CV        | `assets/json/resume.json`  |
| Site settings | `_config.yml`              |

Run `npm run format:check` before committing. Merge content changes into `main` to trigger automatic deployment. The `gh-pages` branch is generated automatically.
